## Local deterministic evidence

The Rust test suite exercises the gateway against a loopback native-RPC stub.
It covers JSON-RPC parsing, method dispatch, parameter validation, OpenRPC
discovery, SSE content type, disabled work, valid delegated work, and scope
separation. These tests prove gateway behavior, not Nano-node compatibility.

## Live V28.2 development-node evidence

On 2026-08-29, the official arm64 Darwin V28.2 binary (build `0d8eea4`) was
run with an isolated `--network dev` ledger. Native RPC returned `version`,
`account_info`, `account_balance`, `account_history`, `block_info`, and
`blocks_info`; the confirmation WebSocket accepted a subscribe request. The
gateway connected to that node, reported ready, and `scripts/devnet-smoke.sh`
passed discovery plus `account_info` translation. A precomputed state block was
submitted successfully through the gateway's `process` method and appeared in
the gateway's confirmation SSE replay. Captured material is in
`fixtures/native/v28.2/`.

This proves the isolated V28.2 development-ledger path, not main-network
behavior or production-scale performance.
