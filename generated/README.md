# Generated V28.2 client artifacts

These files are generated from the gateway's Clean V28.2 OpenRPC document with
the pinned @open-rpc/generator@2.1.1 client generator. Do not edit the client
source manually.

Run make generate-types OPENRPC_SCHEMA_URL=http://127.0.0.1:8090/openrpc.json
after reviewing a schema release. The generated client expects the official
OpenRPC client-js runtime and its normal TypeScript dependencies.
