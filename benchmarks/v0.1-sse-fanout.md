# v0.1 SSE fan-out benchmark

Status: **LOCAL CONTROLLED-SOURCE ONLY**

Captured 2026-08-29 on an arm64 MacBook Air (8 logical CPUs, 8 GiB RAM). The
deterministic HTTP contract test opened eight public SSE streams, connected the
gateway to a controlled native WebSocket source, published one confirmation,
and required every stream to receive the normalized event. Twenty sequential
runs were executed with the same client count and event payload.

Command:

```text
for _ in $(seq 1 20); do
  SSE_FANOUT_CLIENTS=8 cargo test --locked --offline \
    --test http_contract sse_fanout_benchmark -- --nocapture
done
```

Observed time from bridge start until all eight clients received the event
(milliseconds):

| Clients | Runs | p50 | p95 | Min | Max | Mean | Stddev | Delivered |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 8 | 20 | 54.383 | 54.563 | 52.436 | 54.587 | 54.286 | 0.452 | 8/8 each run |

Raw output is retained in [v0.1-sse-fanout.raw](v0.1-sse-fanout.raw). This
measures the gateway's bounded fan-out path with a controlled source; it does
not represent a production Nano node or durable delivery guarantee.
