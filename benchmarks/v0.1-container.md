# v0.1 container benchmark

Status: **POC CONTAINER EVIDENCE**

Captured 2026-08-29 on an arm64 Mac with Docker Desktop (8 logical CPUs,
8 GiB host RAM). The Nano service used the official
`nanocurrency/nano:V28.2` image (`sha256:ae5d9421f87c4620c2285479d95e5e79a2084878058934f7ed6a6b96b6add09e`)
under amd64 emulation, with `--network dev`; the gateway used the local
release image built from this checkout. The Compose fixture used the Dev
network ports (RPC 45000, WebSocket 47000).

Command:

```text
BENCHMARK_OUTPUT_FILE=benchmarks/v0.1-container.raw make container-benchmark
```

Results from the 20 sequential `account_info` requests over HTTP/1.1:

| Measure | Result |
| --- | ---: |
| Compose start to containers running (ms) | 1430 |
| Start to gateway `/readyz` (ms) | 3547 |
| Request p50 (s) | 0.002306 |
| Request p95 (s) | 0.004046 |
| Request min (s) | 0.001885 |
| Request max (s) | 0.014536 |
| Request mean (s) | 0.002996 |
| Request stddev (s) | 0.002685 |
| Nano idle sample RSS | 51.96 MiB |
| Gateway idle sample RSS | 2.535 MiB |
| Native-host Nano process sample | NOT TESTED |

The run also passed the gateway health/readiness checks and was torn down by
the benchmark trap. These are one-host, low-load measurements; they are not a
production capacity claim. Raw request timings are retained in
[v0.1-container.raw](v0.1-container.raw).
