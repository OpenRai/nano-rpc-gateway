Confirmation events

Bounded process-local replay. Send Last-Event-ID to resume; nano.stream_reset reports that replay or live continuity is unavailable.

Receive-only SSE notifications for a pinned Nano node profile. A reset means consumers must reconcile authoritative state with Nano RPC before applying later confirmations.

GET /events/confirmations Last-Event-ID text/event-stream
SSE notification

nano.confirmation

A block confirmation observed from the configured Nano profile.

{
  "jsonrpc": "2.0",
  "method": "nano.confirmation",
  "params": {
    "account": "nano_...",
    "hash": "ABC123",
    "profile": "nano-node/V28.2"
  }
}
SSE notification

nano.stream_reset

Stream continuity was lost or changed; reconcile before continuing.

{
  "jsonrpc": "2.0",
  "method": "nano.stream_reset",
  "params": {
    "profile": "nano-node/V28.2",
    "reason": "replay_unavailable",
    "reconcile": "Query authoritative Nano RPC state before applying new confirmations"
  }
}
