This gateway exposes methods equivalent to Nano node's actions through a JSON-RPC 2.0 API formally described by OpenRPC. It translates ledger calls to that custom JSON RPC interface. Optional confirmation events stream over SSE and are described by AsyncAPI.

  • OpenRPC Playground (JSON-RPC 2.0)
  • AsyncAPI Studio (SSE events)
