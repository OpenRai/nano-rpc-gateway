Nano Gateway

This gateway exposes methods corresponding to Nano node actions through a JSON-RPC 2.0 API formally described by OpenRPC. It translates ledger calls to the node's custom JSON RPC interface. Optional confirmation events stream over SSE and are described by AsyncAPI.
